ホバーで中身が展開されるUIパターン集

ボタンにカーソルを合わせると複数の項目やコンテンツが表示される代表的な5つのUIを、依存ライブラリなし（Vanilla HTML / CSS / JavaScript）で実装したショーケースです。ホバーだけでなくクリック・キーボード操作にも対応しています。

  • ビルド不要・そのままコピー可能
  • ARIA / キーボード操作（↑↓←→ / Esc）対応
  • ホバーブリッジ & 120msの遅延クローズ
  • タッチ端末向けクリックフォールバック

スピードダイアル

Speed Dial

画面右下の丸いボタン（FAB）から、複数のショートカットアクションを時間差アニメーションで展開します。

右下の「＋」ボタンにホバーまたはクリック

実装・アクセシビリティ設計のポイント

ホバーブリッジ & 遅延クローズ

トリガーとパネルの隙間を透明な padding で埋め、カーソル離脱時も 120ms の猶予を持たせることで誤クローズを防いでいます。

キーボード & ARIA 同期

aria-expanded と aria-haspopup を自動更新し、↑↓ / Home / End / →← / Escape キーでの移動と終了に対応しています。

タッチ端末フォールバック

pointerType === "touch" ではホバー発火を抑止し、タップによる開閉と外側タップでの閉じる挙動に切り替わります。

動きの軽減への配慮

OS設定の prefers-reduced-motion: reduce を検知し、アニメーションを自動的に無効化します。
